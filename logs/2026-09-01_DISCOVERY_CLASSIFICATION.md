# 2026-09-01 발견자료 분류

## SH 국민임대 SNS 홍보 게시물

사용자 제공 캡처 문구:

- 보증금 3,200만원
- 월 25만원
- 강남·마곡·강일
- 1,973세대

판정:

- 새 공고가 아님.
- 이미 분석 후 사용자 판단으로 패스한 `SH 2026년 국민임대주택 1,973세대` 공고를 재소개한 SNS 홍보자료로 분류.
- SNS의 평균 임대조건 문구를 개별 단지/형/호실의 확정 임대조건으로 사용하지 않음.
- `서울 사는 무주택자라면 일단 넣어두면 좋다` 같은 홍보 문구를 신청자격 판정 근거로 사용하지 않음.
- 해당 자료가 다시 발견되어도 국민임대 패스 상태를 자동 해제하지 않음.
- 앱에서는 `후보 발견용 자료`에만 표시.

## SH 행복주택 자료

- 사용자 제공 공고문 소득표는 이번 회차 근거자료로 보존.
- 집지켜 후보/가격 화면은 후보발견용으로 보존.
- 청년 공급 여부, 실제 공급/예비 수, 공식 보증금/월세/전환조건은 SH 공식 공급표·임대조건표로 재검증 후 확정.
