### 상세 보고 규칙 회수·강화

과거 프로젝트 대화/인수인계에서 사용하던 상세 양식을 다시 기준 문서로 복원했다.

- `docs/REPORTING_AND_MAP_RULES.md` 신규 생성.
- README와 HANDOFF에서 상세 보고 규칙을 필수 기준으로 연결.
- `templates/REPORT_TEMPLATE.md`를 단순 양식에서 실전 상세 양식으로 확장.
- 일정 그룹별 지도 + 필요 시 공고별 개별 지도 규칙 강화.
- 정확한 도로명주소 + 건물명 표시 강화.
- 가까운 역/노선/도보 + 가능하면 평일 낮 네이버지도 지하철 기준 강남·판교 이동시간 규칙 명문화.
- 이번 회차 최소/기본/최대 보증금·월세와 보증금 전환 조건 확인 규칙 강화.
- 자격을 `✅ 가능 / ⚠️ 추가확인 / ❌ 불가`로 실제 공고 기준 판정하도록 강화.
- 대출 제도상 최대, 현실 예상 대출, 자기자금, 월이자, 월세, 관리비, 총 월주거비 계산 규칙 복원.
- 같은 공고 내부뿐 아니라 서로 다른 공고 사이 중복신청 가능 여부 확인 규칙 강화.
- 택1 그룹은 후보 순위를 매기고 추천 선택을 명시하도록 복원.
- 공고명 바로 아래 `공식 공고 | 공고 PDF | 신청하기` 또는 `공식 공고 | 결과조회` 링크 배치 규칙 강화.
- 패스 공고 상세·지도·추천·행동순위 반복 금지 재강화.
- 오늘 마감 공고를 현재시각 확인 없이 종료로 처리하지 않도록 재강화.

## 이후 기록 원칙

작업을 수행할 때마다 중요한 변경을 날짜별로 누적한다.

기록 대상:

- MASTER RULES 변경
- 상세 보고/지도 규칙 변경
- 신규 신청/상태 변경
- 결과/예비/서류/계약 변화
- 패스/보류 결정
- 탐색 소스 추가
- 중요한 판정 정정
- 보고 형식/지도 규칙 변경

과거 이력은 특별한 이유 없이 삭제하지 않는다.
