# 사용자 출력 최우선 규칙

최종 갱신: 2026-08-30 KST

이 문서는 사용자가 직접 지정한 최신 출력 선호를 기록한다. `docs/REPORTING_AND_MAP_RULES.md`, `templates/REPORT_TEMPLATE.md` 등 기존 문서와 충돌하면 **이 문서를 우선 적용**한다.

## 1. 추천 순위 숫자 금지

청약 보고에서 후보를 `1순위`, `2순위`, `3순위`처럼 숫자로 서열화하지 않는다.

또한 추천 별점(`★★★★★`)을 기본 표식으로 사용하지 않는다.

후보의 중요도·긴급도·상태는 **이모티콘으로만 시각적으로 표시**한다.

예:
- 🔴⏰ 오늘/24시간 내 마감·제출
- 🟠⚠️ 2~3일 내 중요 일정
- 🟢 현재 접수 중
- 🔵 곧 시작
- 🔥 특히 검토 가치가 높은 후보
- ✅ 신청완료
- 🎯 결과확인/발표
- 📄 서류
- 🏠 계약/입주
- ⚠️ 택1/중복주의
- ⏸ 보류
- ❌ 패스

공고 제목 예시:
`🔥🔵 SH 국민임대 — 8/31 접수 시작`

금지 예시:
`1순위 SH 국민임대 ★★★★★`

## 2. 공식 자격상의 순위는 예외

공고 자체의 법정/공식 선정기준인 `1순위·2순위·3순위·4순위`는 사용자 추천순위가 아니므로 필요한 경우 정확히 표시한다.

예: 양천구 청년협동조합 공동체주택 신청서의 `4순위`.

## 3. 지도 규칙 유지

숫자 순위를 없애더라도 지도는 생략하지 않는다.

- 오늘·내일
- 2~3일 내
- 4~7일 내
- 그 이후 예정
- 이미 신청한 공고

각 일정 그룹별 지도 위젯을 유지하고, 공식 정확주소가 확인된 후보만 핀을 표시한다.

## 4. 공고 상세 규칙 유지

순위 숫자만 제거한다. 다음 상세정보는 기존 규칙대로 유지한다.

- 공식 공고/PDF/신청/결과조회 링크
- 정확주소
- 역/노선/도보
- 강남·판교 통근
- 이번 회차 가격
- 최소/기본/최대 보증금 전환
- 자격
- 대출·자기자금·월이자·월세·관리비·총 월주거비
- 중복신청/택1
- 신청 후 결과·서류·계약·입주 추적
