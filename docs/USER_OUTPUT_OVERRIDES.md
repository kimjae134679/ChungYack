# 사용자 출력 최우선 규칙

최종 갱신: 2026-08-31 KST

이 문서는 사용자가 직접 지정한 최신 출력 선호를 기록한다. `docs/MASTER_RULES.md`, `docs/REPORTING_AND_MAP_RULES.md`, 템플릿 등 기존 문서와 충돌하면 **이 문서를 우선 적용**한다.

## 1. 추천 숫자순위/별점 금지

청약 보고에서 후보를 `1순위`, `2순위`, `3순위`처럼 숫자로 서열화하지 않는다.

또한 `★★★★★` 같은 추천 별점을 사용하지 않는다.

후보의 중요도·긴급도·상태는 이모티콘으로 표시한다.

- 🔥 검토가치 높음
- 🔴⏰ 오늘/24시간 내 마감·제출
- 🟠⚠️ 2~3일 내 중요 일정
- 🟢 현재 접수 중
- 🔵 곧 시작
- ✅ 신청완료
- 🎯 결과확인/발표
- 📄 서류
- 🏠 계약/입주
- ⚠️ 택1/중복주의
- ⏸ 보류
- ❌ 패스

금지 예시:
`1순위 SH 국민임대 ★★★★★`

허용 예시:
`🔥🔵 SH 국민임대 — 8/31 접수 시작`

## 2. 공고 자체 공식 순위는 예외

공고 자체의 법정/공식 선정기준인 `1순위·2순위·3순위·4순위`는 사용자 추천순위가 아니므로 정확히 표시한다.

예: 양천구 청년협동조합 공동체주택 신청서의 `4순위`.

## 3. 지도 — 반드시 보여줄 것 / 최우선

**지도는 생략하지 않는다. 일정 그룹별로 반드시 표시한다.**

- 오늘·내일
- 2~3일 내
- 4~7일 내
- 그 이후 예정
- 이미 신청한 공고

각 그룹마다 별도 지도 위젯을 둔다.

고정 순서:
`그룹 제목 → 상태요약 → 지도 → 공고 상세`

강제:

- 후보가 1곳뿐이어도 지도 표시.
- 전체 후보를 지도 하나에 합치지 않음.
- 다른 일정 그룹을 한 지도에 섞지 않음.
- 이미 신청한 공고는 전용 지도.
- 정확주소가 공식 확인된 곳만 핀 표시.
- 주소가 애매하면 추정 핀 금지.
- 패스/탈락 공고는 지도에서 제거.
- 기술적으로 지도 위젯을 쓸 수 없는 경우에만 불가 사유와 역/노선/강남·판교 접근성으로 대체.

**지도 누락은 잘못된 보고로 간주한다.**

## 4. 공고 상세 규칙 유지

다음 상세정보는 가능한 한 매 공고에 표시한다.

- 공식 공고 / PDF / 신청 / 결과조회 링크
- 정확주소
- 가까운 역·노선·도보
- 강남/판교 이동시간
- 실제 모집호수 / 예비인원
- 공가/예비 구분
- 이번 회차 보증금·월세
- 최소/기본/최대 보증금 전환
- 자격
- 부모 소득·자산 포함 여부
- 대출 가능성
- 자기자금
- 월이자
- 월세
- 관리비
- 총 월주거비
- 서로 다른 공고 간 중복신청 가능 여부

## 5. 국민임대 출력

국민임대는 대형 공고 한 줄로 뭉뚱그리지 않는다.

실제 단지별로 펼쳐서 보여준다.

특히:

- 공가 모집 / 예비 모집 구분
- 공가 0인지 실제 공가 존재인지 구분
- 타입/면적/공급호수
- 이번 회차 가격

을 명확하게 표시한다.

## 6. 현재상태 처리

- 이미 신청한 공고는 신규 후보와 분리해서 끝까지 추적.
- 사용자가 직접 `탈락`이라고 확인한 공고는 현재 보고/결과확인/지도에서 제거하고 원장 이력만 유지.
- 패스는 상세/지도/행동목록에서 제거.
- 보류는 영구 제외가 아니며 신규 가격·자격·일정·공급호수 확인 시 재검토 가능.

현재 살아 있는 주요 추적 기준:

- UNIT125 18A
- 2026년 양천구 청년협동조합 공동체주택(신정동)
- 호반써밋 양재
- 비바힐스강변 — 신청 진행중

더포디엄830 25B는 사용자 확인 `탈락`으로 현재 지도·결과추적에서 제거.

현재 추가 패스:

- 서울번동3 행복주택
- 부천영상 지역전략산업지원 행복주택

## 7. 사용자 직접 상태 최우선

`신청했어 / 넣자 / 탈락 / 예비 몇 번 / 패스 / 보류 / 서류 냈어 / 계약했어` 같은 사용자의 직접 확인은 공개 웹검색보다 우선한다.

가능하면 즉시 `data/tracking_registry.md`와 `STATUS.md`에 반영한다.
