## 0. 프로젝트 최상위 목적

이 프로젝트는 단순히 `오늘 올라온 공고`를 찾는 프로젝트가 아니다.

항상 다음 전체 상태를 관리한다.

- 현재 신청 가능한 공고
- 곧 신청이 시작되는 공고
- 새로 게시된 공고
- 이미 신청한 공고
- 신청 진행중인 공고
- 결과발표
- 예비순번
- 서류제출
- 계약
- 입주 일정

이미 신청한 공고는 신청으로 끝내지 않는다.

`신청 → 결과 → 당첨/예비 → 서류 → 계약 → 입주`

최종 목표:

**많이 찾고 → 공식자료로 걸러내고 → 사용자가 실제 신청 가능한 것만 남기고 → 입지·가격·당첨가능성을 비교하고 → 신청 후 결과까지 끝까지 추적한다.**

## 1. `오늘꺼 알려줘`의 의미

단순 신규 게시물 검색이 아니다. 실행 시 동시에 다음을 수행한다.

- 현재 신청 가능한 공고 확인
- 곧 접수 시작하는 공고 확인
- 신규 게시 공고 확인
- 숨은 지자체/소규모 공고 역검증
- 이미 신청한 공고 결과/예비/서류/계약/입주 갱신
- 신청 진행중 공고 상태 갱신
- 마감 임박 공고 확인
- 결과발표 임박/경과 공고 확인
- 패스/보류 상태 정리
- 민간 집계앱/유튜브에서 발견된 누락 후보 역검증

기준은 `게시일`이 아니라 **실제 신청 가능 시점과 후속 일정**이다.

---

## 2. KST 현재시각 판정 — 강제

- 매 실행마다 한국시간(KST) 현재시각을 확인한다.
- `아직 시작 전 / 접수 중 / 몇 시간·몇 분 남음 / 마감 / 발표시각 경과`를 정확히 구분한다.
- 오늘 마감이면 정확한 마감시각과 가능하면 남은 시간을 표시한다.
- 이미 발표시각이 지났다면 `발표 예정`이라고 쓰지 않는다.
- 이전 보고와 판단이 달라졌다면 최상단에 `중요 정정`을 둔다.
- 신청 UI가 닫혀 보여도 공고문에 적힌 접수방법과 마감시각을 다시 확인한다.

## 8. 최종 검증 순서

민간/앱/유튜브/웹검색에서 발견
→ 공식 공고 페이지
→ 첨부 모집공고 PDF
→ 이번 회차 공급호수표
→ 이번 회차 임대조건표
→ 공식 단지 페이지
→ 실제 신청 페이지

- 웹페이지 요약보다 공식 PDF 우선.
- 이전 모집회차 가격을 이번 모집에 사용 금지.
- 공식자료로 확인되지 않은 숫자·주소·가격은 추정 금지.
- 유튜브 제목/썸네일의 최저가격을 전체 공고 가격처럼 사용 금지.

## 10. 추천 숫자순위/별점 금지 — 최신 최우선

사용자에게 보여주는 추천 서열에 다음을 쓰지 않는다.

- `1순위 / 2순위 / 3순위`
- `★★★★★` 등 별점

대신 상태·긴급도·검토가치는 다음 이모티콘만으로 표현한다.

- 🔥 핵심 검토가치
- 🔴⏰ 오늘/24시간 내 최긴급
- 🟠⚠️ 2~3일 내 중요
- 🟢 접수 중
- 🔵 곧 시작
- ✅ 신청완료
- 🎯 결과확인/발표
- 📄 서류
- 🏠 계약/입주
- ⚠️ 중복·택1 주의
- ⏸ 보류
- ❌ 패스

단, **공고 자체의 공식 선정순위는 예외**다.

예: 신정동 공고의 `4순위`는 사용자 추천순위가 아니라 공식 선정기준이므로 그대로 표시 가능.

## 11. 일정 그룹

반드시 다음 순서로 구분한다.

1. 오늘·내일
2. 2~3일 내
3. 4~7일 내
4. 그 이후 예정
5. 이미 신청한 공고

숫자는 일정 그룹 순서를 설명하기 위한 문서 구조일 뿐, 사용자 추천순위를 의미하지 않는다.

## 12. 지도 규칙 — 최우선 강제 규칙

**지도는 선택사항이 아니다. 일정 그룹별로 반드시 표시한다.**

반드시 아래 그룹마다 별도 지도 위젯을 둔다.

- 오늘·내일
- 2~3일 내
- 4~7일 내
- 그 이후 예정
- 이미 신청한 공고

고정 배치:

`그룹 제목 → 상태요약 → 지도 → 공고 상세`

강제 규칙:

- 모든 후보를 하나의 지도에 몰아넣지 않는다.
- 서로 다른 일정 그룹을 한 지도에 섞지 않는다.
- 그룹에 후보가 1곳만 있어도 지도 표시.
- 이미 신청한 공고도 신규 후보와 분리된 전용 지도 표시.
- 택1 후보는 같은 일정 그룹 안에서 함께 비교 가능.
- 정확한 주소가 공식자료에서 확인된 곳만 핀을 찍는다.
- 주소가 애매하면 억지로 추정 핀을 찍지 않는다.
- 패스/탈락 공고는 지도에서 제거한다.
- 보류 공고는 해당 보고에서 적극 검토 대상이 아닐 경우 지도에 강제로 넣지 않는다.

지도 위젯 자체가 기술적으로 불가능한 경우에만 다음으로 대체한다.

`지도 불가 사유 + 지역 + 가까운 역/노선 + 강남·판교 접근성`

**지도 누락은 보고 형식 오류로 취급한다.**

---

## 13. 정확한 주소 규칙

모든 후보마다 별도 줄:

`정확한 주소: ○○`

- 가능하면 도로명주소 + 건물명.
- 공식자료 기준.
- 지도 핀도 이 주소 기준.
- 확인되지 않으면 추정 금지.
- 확인 불가 시 `정확한 주소 확인 필요`.

---

## 14. 국민임대 단지 단위 분해 — 강제

국민임대 대형 모집을 `공고 하나`로만 요약하지 않는다.

세곡 / 강일 / 고덕 / 마곡 / 우면 / 내곡 / 장지 / 위례 / 신정 등 실제 공급단지 단위로 펼쳐서 본다.

단지별 확인:

- 실제 공급단지
- 공가 모집인지 예비 모집인지
- `공가 0`인지 실제 공가가 있는지
- 타입
- 전용면적
- 공급호수
- 예비인원
- 이번 회차 보증금/월세
- 위치/교통
- 사용자의 실제 신청 가능성

공가 0인 단지를 `즉시 입주 가능한 공가`처럼 표현하면 안 된다.

## 15. 공고별 필수 출력 항목

### 공식 링크
신규 후보:
`공식 공고 | 공고 PDF | 신청하기`

이미 신청:
`공식 공고 | 결과조회`

별도 폼이면 `실제 신청폼` 추가.

### 접수·일정
- 접수 시작/마감
- 정확한 마감시각
- 현재 상태
- 남은 시간 가능하면 표시
- 서류/발표/계약/입주 일정

### 위치
- 지역
- 단지
- 가까운 역/노선
- 도보거리/도보시간
- 강남 이동시간
- 판교 이동시간

### 정확한 주소
- 공식 도로명주소 + 건물명

### 모집
- 실제 모집구분
- 일반/특별
- 타입
- 전용면적
- 실제 모집호수
- 예비인원
- 공가/예비 구분

### 금액
이번 회차 실제 기준:

- 최소보증금 / 최대월세
- 기본보증금 / 기본월세
- 최대보증금 / 최소월세
- 보증금 전환조건

확인 불가 시 `이번 회차 임대조건표 공식 확인 필요`.

### 자격
- 나이
- 미혼 여부
- 무주택
- 세대주/세대원
- 소득
- 자산
- 자동차
- 지역/거주/근무 요건
- 청약통장
- 납입횟수
- 부모 소득·자산 포함 여부
- 심사단위
- 공식 선정순위
- 1인가구 제한
- 기타 실제 당락조건

### 대출·실부담
단순 `80~90% 가능`으로 끝내지 않는다.

가능하면:

- 제도상 최대
- 해당 주택이 실제 대출 대상인지
- 현실 예상 대출액
- 필요한 자기자금
- 예상 월이자
- 월세
- 관리비
- 최종 월 주거비

검토 가능한 제도:

- 청년전용 버팀목전세자금
- 청년전용 보증부월세대출
- 일반 버팀목
- 서울시 청년 임차보증금 이자지원
- HUG/HF 보증
- 단지/은행 협약대출
- 기타 최신 공식 금융지원

은행/HUG/HF 심사 전 확정치처럼 말하지 않는다.

### 중복신청
같은 모집 내부뿐 아니라 서로 다른 공고 간에도 동시에 신청 가능한지 확인한다.

- 1세대 1주택
- 같은 모집 하나만 신청
- 타 공고와 중복 가능/불가
- 중복 시 무효 여부

필요 시 `⚠️ 택1`로 표시한다.

---

## 16. 교통·통근 규칙

가능하면 가장 가까운 지하철역 기준으로 확인한다.

- 역명
- 노선
- 도보시간
- 강남역 이동시간
- 판교역 이동시간

가능하면 평일 낮 지도/대중교통 경로 기준으로 확인한다. 임의 직선거리로 대체하지 않는다.

---

## 17. 사용자 상태가 공식 웹검색보다 우선

사용자가 직접 다음 상태를 말하면 즉시 원장에 반영한다.

- `신청했어 / 넣었어`
- `넣자 / 신청 진행중`
- `탈락`
- `예비 ○번`
- `패스 / 넘기자 / 제외`
- `보류`
- `서류 냈어`
- `계약했어`

사용자 직접 확인 상태가 공개 웹검색보다 우선한다.

가능하면 `data/tracking_registry.md`와 `STATUS.md`에 동기화한다.

---

## 18. 이미 신청한 공고 / 탈락 처리

이미 신청한 공고는 신규 후보와 분리해 끝까지 추적한다.

현재 살아 있는 추적 기준:

- UNIT125 18A — ✅ 신청완료 / 예비 80번대
- 2026년 양천구 청년협동조합 공동체주택(신정동) — ✅ 신청완료 / 공식 선정기준 4순위
- 호반써밋 양재 — 결과/후속 상태 추적
- 비바힐스강변 — 신청 진행중

탈락:

- 더포디엄830 25B — 사용자 직접 확인 `탈락`
- 현재 보고/결과확인/기신청 지도에서 제거
- 원장 이력에만 유지

사용자가 탈락이라고 확인한 공고는 이후 `오늘꺼`에서 결과확인 대상으로 반복하지 않는다.

---

## 19. 패스 / 제외 / 보류

사용자가 `넘기자 / 패스 / 제외`라고 결정하면:

- 상세정보 반복 금지
- 지도 제외
- 추천/검토 표시 제외
- 행동 우선목록 제외
- 일정 종료 전 필요 시 한 줄만 유지

현재 추가 패스:

- 서울번동3 행복주택
- 부천영상 지역전략산업지원 행복주택

기존 패스도 계속 유지하며 상세/지도에 재등장시키지 않는다.

보류는 패스와 다르다.

- 금천구 1인가구 청년 맞춤형주택 — ⏸ 보류
- 새 가격·자격·일정·공급호수 등이 나오면 재검토 가능

## 20. 최종 보고 구조

1. 기준시각 + 중요정정
2. 전체 긴급요약
3. 오늘·내일
   - 상태요약
   - **그룹 전용 지도 필수**
   - 공고 상세
4. 2~3일 내
   - 상태요약
   - **그룹 전용 지도 필수**
   - 공고 상세
5. 4~7일 내
   - 상태요약
   - **그룹 전용 지도 필수**
   - 공고 상세
6. 그 이후 예정
   - 상태요약
   - **그룹 전용 지도 필수**
   - 공고 상세
7. ✅ 이미 신청한 공고
   - 단계요약
   - **기신청 전용 지도 필수**
   - 추적 상세
8. 제외/패스
   - 필요 시 한 줄
9. 오늘 행동 우선순위
   - 숫자 추천순위는 쓰지 않고 긴급도/상태 이모티콘으로 정렬

## 21. 절대 하지 말 것

- 공고 게시일만 보고 오늘 후보 판단
- 현재 KST 마감시각 확인 없이 종료 처리
- 이전 회차 임대료 가져오기
- 공식자료 없는 주소/가격 추정
- 모든 후보를 하나의 지도에 몰아넣기
- **일정 그룹 지도 누락**
- 주소 애매한 후보에 억지 핀 찍기
- 패스 공고 상세/지도 반복
- 탈락 공고 결과확인 반복
- 이미 신청한 공고를 신규 추천으로 재등장
- 청년+신혼 혼합을 신혼전용처럼 제외
- 사용자 추천 숫자순위/별점 사용
- 공고 공식 선정순위까지 지워버리기
- 국민임대를 공고 하나로만 뭉뚱그려 공가 여부를 숨기기
- `80% 대출 가능`만 적고 자기자금/월이자 계산 생략
- 개인 결과를 공개검색만으로 추측
- 민간 앱에 있는 공고 누락을 이유 확인 없이 방치

## 22. 자동화

사용자가 새로 요청하지 않는 한 청약 자동화 스케줄을 임의로 새로 만들지 않는다.

기존 자동화가 존재하고 수정 요청이 있을 경우 새 자동화를 추가하기 전에 기존 자동화 중복 여부를 먼저 확인한다.
