# 청약2 상세 보고·지도·비용 판정 규칙

최종 갱신: 2026-08-30 KST

이 문서는 `docs/MASTER_RULES.md`를 보완하는 **실전 보고 출력 규칙**이다. `오늘꺼 알려줘` 및 수동/자동 보고 시 반드시 함께 적용한다.

## 1. 고정 출력 순서

1. 기준시각(KST) + 중요 정정
2. 전체 긴급요약
3. 오늘·내일
4. 2~3일 내
5. 4~7일 내
6. 그 이후 예정
7. ✅ 이미 신청한 공고
8. ⚠️ 택1/중복주의 그룹
9. 제외/패스 한 줄 목록
10. 오늘 행동 우선순위

`오늘꺼 알려줘`는 오늘 게시된 공고만 뜻하지 않는다. 현재 신청 가능, 곧 시작, 신규 게시, 기신청 결과/예비/서류/계약/입주를 동시에 갱신한다.

## 2. 상태 표식

- 🔴⏰: 오늘 또는 24시간 내 마감/제출 등 최긴급
- 🟠⚠️: 2~3일 내 중요한 시작/마감
- 🔥: 같은 그룹 안 핵심 추천
- 🟢: 현재 접수 중이며 비교적 여유
- 🔵: 곧 접수 시작
- ✅: 이미 신청 완료
- 🎯: 결과발표/결과조회
- 📄: 서류대상/서류제출
- 🏠: 계약/입주
- ⚠️ 택1: 중복신청 불가 또는 하나만 선택해야 함

각 일정 그룹 상단에는 가능하면 `🔴 오늘 마감 N | 🟢 접수 중 N | 🔵 곧 시작 N`처럼 상태 개수를 요약한다.

## 3. 지도 규칙

모든 후보를 하나의 지도에 몰아넣지 않는다.

반드시 일정 그룹별로 나눈다.

- 오늘·내일
- 2~3일 내
- 4~7일 내
- 그 이후 예정
- 이미 신청한 공고

기본 배치:

`그룹 제목 → 상태요약 → 그룹 지도 → 공고 상세`

후보가 1개뿐이어도 위치 파악에 도움이 되면 지도 표시를 원칙으로 한다.

또한 공고를 읽는 중 바로 위치를 파악하는 것이 유용한 경우 공고 상세 아래에 개별 위치지도를 추가할 수 있다.

지도 핀은 공식자료에서 확인된 정확한 주소만 사용한다. 주소가 불명확하면 추정 핀을 만들지 않는다.

## 4. 정확한 주소

모든 후보에 가능한 경우 별도 줄로 아래를 적는다.

`정확한 주소: 공식 도로명주소 + 건물명`

공식자료에서 확인되지 않으면 `정확한 주소 확인 필요`라고 적고 임의 추정하지 않는다.

## 5. 교통·통근

가능한 경우 가장 가까운 지하철역 기준으로 다음을 확인한다.

- 역명
- 노선
- 도보거리/도보시간
- 강남역 이동시간
- 판교역 이동시간

강남/판교 이동시간은 가능하면 **평일 낮 네이버지도 지하철 기준**으로 확인한다. 자동차시간, 직선거리, 임의 추정치로 대체하지 않는다.

## 6. 공고별 필수 상세 항목

### A. 공식 링크
공고명 바로 아래에 배치한다.

신규 후보:
`공식 공고 | 공고 PDF | 신청하기`

이미 신청:
`공식 공고 | 결과조회`

별도 신청폼이 있으면 `실제 신청폼`을 추가한다.

링크를 답변 맨 아래에 몰아두지 않는다.

### B. 접수·일정
- 접수 시작
- 접수 마감
- 정확한 마감시각
- 서류대상 발표
- 서류제출
- 당첨발표
- 계약
- 입주

현재시각과 마감시각을 비교해 `현재 신청 가능`, `몇 시간/몇 분 남음`, `아직 시작 전`, `마감`을 정확히 표시한다.

### C. 공고/모집
- 기관
- 모집유형
- 신규/추가/예비/잔여/자격완화/상시 등
- 일반/특별
- 모집계층
- 타입
- 전용면적
- 실제 모집호수
- 예비인원

### D. 위치
- 지역/권역
- 단지명
- 정확한 주소
- 가장 가까운 역
- 노선
- 도보시간
- 강남 이동시간
- 판교 이동시간

### E. 이번 회차 임대조건
반드시 이번 모집회차 공식 자료를 우선한다.

가능하면:
- 최소보증금 / 최대월세
- 기본보증금 / 기본월세
- 최대보증금 / 최소월세
- 보증금 전환 조건

이전 회차 가격, 블로그 가격, 유튜브 썸네일 가격, 단지 전체 최저가격을 이번 회차 특정 타입 가격처럼 사용하지 않는다.

`가격은 확인 필요`라고 쉽게 넘기지 말고 공식 PDF/공급표/임대조건표까지 최대한 직접 확인한다. 그래도 공식 이번 회차 값이 확인되지 않을 때만 `이번 회차 임대조건표 공식 확인 필요`라고 명시한다.

### F. 자격
실제 공고 기준으로 확인한다.

- 나이
- 미혼 여부
- 무주택
- 세대주/세대원
- 소득
- 자산
- 자동차
- 지역/거주/근무 요건
- 청약통장/납입횟수
- 부모 소득·자산 포함 여부
- 심사단위
- 1인가구 전용면적 제한
- 기타 실제 당락조건

출력은 가능하면 `✅ 가능 / ⚠️ 추가확인 / ❌ 불가`로 판정하고 이유를 붙인다.

### G. 대출·실부담
보증금이 높다는 이유만으로 제외하지 않는다.

검토 가능한 제도 예:
- 청년전용 버팀목
- 청년전용 보증부월세대출
- 일반 버팀목
- 서울시 청년 임차보증금 지원
- HUG/HF 보증
- 단지/은행 협약대출

공고/상품 조건이 확인되면 다음을 계산한다.

- 제도상 최대 대출
- 실제 대상 여부
- 현실 예상 대출액
- 필요한 자기자금
- 예상 월이자
- 월세
- 관리비
- 최종 예상 월 주거비

`보증금의 80% = 실제 대출 80%`처럼 단순 계산하지 않는다. 상품별 한도, 소득, 자산, 주택형태, 보증심사를 구분한다.

### H. 중복신청·택1
같은 공고 내부뿐 아니라 **서로 다른 공고 A와 B를 동시에 신청해도 되는지**까지 확인한다.

1세대 1주택, 중복무효, 동일 날짜 타지역 중복불가 등이 있으면 별도 `⚠️ 택1 그룹`으로 묶는다.

택1 그룹 안에서 후보별 순위를 매기고 마지막에 `추천 선택: ○○`를 명시한다.

### I. 판단
- 신청 가능성
- 당첨 가능성
- 입지
- 가격
- 자기자금/월부담
- 모집규모
- 신청 난이도
- 제출서류 부담
- 장기거주 가능성
- 추천 이유
- 주의점
- 오늘 할 행동

## 7. 추천 정렬

같은 그룹 안에서는 원칙적으로 다음을 종합한다.

1. 현재 실제 신청 가능 여부와 마감 임박도
2. 자격 적합성
3. 위치
4. 강남/판교 접근성
5. 보증금·월세·대출 후 자기자금
6. 모집규모·당첨 가능성
7. 주거수준/장기거주
8. 신청/서류 난이도

오늘 17시 마감과 23시 마감이 있으면 17시 마감을 먼저 행동순위에 올린다. 같은 일정이면 실제 조건과 입지를 비교한다.

## 8. 포함/제외

신혼부부 전용만 신청 가능한 모집은 기본 제외한다.

하지만 청년+신혼 혼합, 청년+대학생+신혼, 여러 계층 공용 모집에서 사용자가 청년 자격으로 신청 가능하면 포함한다.

검색 단계에서 멀다는 이유만으로 제외하지 않는다.

`발견 → 자격 검토 → 가격 검토 → 접근성에서 감점`

## 9. 탐색 범위

중앙/광역 공식기관만 보고 종료하지 않는다.

- LH / SH / GH / iH / HUG
- 서울주거포털 / 청년안심주택
- 서울시 / 경기도 / 필요 시 인천
- 서울 25개 자치구 각각
- 경기 전 시·군 각각
- 도시공사/출자·출연기관
- 고시공고/주거복지/청년정책/1인가구 지원
- 1인가구 맞춤형주택
- 수요자맞춤형주택
- 청년협동조합주택
- 도시형생활주택
- 특화주택
- 지자체 자체 청년주택/임대주택
- 청년 매입임대/행복주택/국민임대/통합공공임대
- 공공지원민간임대/청년안심주택/HUG 든든전세
- 신규/예비/추가/자격완화/잔여/재공급/상시모집

민간 집계와 일반 검색, 청약 전문 유튜브도 후보 발견용으로 활용하되 최종 근거는 공식 공고와 PDF로 재검증한다.

## 10. 이미 신청한 공고

신청완료 공고는 신규추천 목록에서 제거하고 별도 `✅ 이미 신청한 공고` 그룹으로 관리한다.

`신청 → 결과 → 당첨/예비 → 서류 → 계약 → 입주`

끝까지 추적한다.

개인 결과는 공개검색으로 추정하지 않는다. 사용자가 직접 알려준 결과를 우선한다.

## 11. 패스·보류

사용자가 `패스 / 넘기자 / 제외`라고 결정한 공고는:

- 상세정보 반복 금지
- 지도 제외
- 추천순위 제외
- 행동순위 제외
- 장황한 설명 금지

일정 종료 전 필요하면 한 줄만 유지한다.

`❌ 공고명 — 접수기간 — 사용자 판단으로 패스`

보류는 패스와 다르다. 새 가격/자격/공급호수/일정 등이 나오면 재평가한다.

## 12. 과거 오류 재발 방지

- 오늘 마감 공고를 현재시각 확인 없이 종료로 처리하지 않는다.
- 단지 전체 가격과 이번 모집 특정 타입 가격을 혼합하지 않는다.
- 단지 신청창이 닫혔다는 이유만으로 공식 접수 종료를 단정하지 않는다.
- 서로 다른 공고끼리 중복 신청 가능 여부를 누락하지 않는다.
- 위치 표현은 정확주소와 실제 역 기준으로 한다.
- 신청완료 이후 결과/서류/계약/입주 추적을 잊지 않는다.
