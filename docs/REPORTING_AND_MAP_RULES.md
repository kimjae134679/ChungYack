# 청약2 상세 보고·지도·비용 판정 규칙

최종 갱신: 2026-08-31 KST

이 문서는 `docs/MASTER_RULES.md`를 보완하는 실전 보고 출력 규칙이다. `오늘꺼 알려줘` 및 수동/자동 보고 시 반드시 함께 적용한다.

## 1. 고정 출력 순서

1. 기준시각(KST) + 중요 정정
2. 전체 긴급요약
3. 오늘·내일
4. 2~3일 내
5. 4~7일 내
6. 그 이후 예정
7. ✅ 이미 신청한 공고
8. ⚠️ 택1/중복주의
9. 제외/패스 한 줄 목록
10. 오늘 행동 우선순위

추천 숫자순위와 별점은 사용하지 않는다.

## 2. 상태 표식

- 🔴⏰: 오늘 또는 24시간 내 마감/제출 등 최긴급
- 🟠⚠️: 2~3일 내 중요한 시작/마감
- 🔥: 특히 검토가치 높은 후보
- 🟢: 현재 접수 중
- 🔵: 곧 접수 시작
- ✅: 신청완료
- 🎯: 결과발표/결과조회
- 📄: 서류대상/서류제출
- 🏠: 계약/입주
- ⚠️: 중복/택1/중요주의
- ⏸: 보류
- ❌: 패스

`1순위, 2순위, ★★★★★` 같은 사용자 추천 서열 표시는 금지한다.

단, 공고 자체의 공식 선정기준인 `1순위~4순위` 등은 그대로 표기한다.

## 3. 지도 규칙 — 최우선 / 생략 금지

**지도는 선택사항이 아니다. 일정 그룹별 필수 출력 요소다.**

반드시 아래 그룹별로 각각 독립된 지도 위젯을 둔다.

- 오늘·내일
- 2~3일 내
- 4~7일 내
- 그 이후 예정
- 이미 신청한 공고

고정 배치:

`그룹 제목 → 상태요약 → 지도 → 공고 상세`

강제사항:

- 그룹에 후보가 1개뿐이어도 지도 표시.
- 서로 다른 일정 그룹을 한 지도에 섞지 않는다.
- 전체 후보 통합 지도 하나로 대체하지 않는다.
- 이미 신청한 공고는 신규 후보와 분리된 전용 지도 사용.
- 패스/탈락 공고는 지도에서 제거.
- 공식자료에서 정확주소가 확인된 장소만 핀 표시.
- 주소가 불명확하면 추정 핀을 만들지 않는다.
- 한 그룹에 정확주소 확인 후보가 0개면 억지 핀 대신 `지도에 표시할 공식 정확주소 확인 후보 없음`을 명시하고 각 공고 상세에 `정확한 주소 확인 필요`를 표시한다.
- 지도 위젯 자체가 기술적으로 불가능한 경우에만 `지도 불가 사유 + 지역 + 가까운 역/노선 + 강남·판교 접근성`으로 대체한다.

**지도 누락은 보고 형식 오류로 취급한다.**

## 4. 정확한 주소

모든 후보에 별도 줄:

`정확한 주소: 공식 도로명주소 + 건물명`

공식자료에서 확인되지 않으면:

`정확한 주소 확인 필요`

임의 추정 금지.

## 5. 시간 판정

매 보고마다 KST 현재시각을 확인하고 다음을 구분한다.

- 아직 시작 전
- 접수 중
- 몇 시간/몇 분 남음
- 마감
- 발표 전
- 발표시각 경과

오늘 마감 공고는 반드시 마감시각과 가능하면 남은 시간을 표시한다.

## 6. 교통·통근

가능한 경우 가장 가까운 지하철역 기준:

- 역명
- 노선
- 도보거리/도보시간
- 강남역 이동시간
- 판교역 이동시간

가능하면 평일 낮 지도/대중교통 기준으로 확인한다. 직선거리 임의 추정 금지.

## 7. 공고별 필수 상세 항목

### A. 공식 링크

신규 후보:
`공식 공고 | 공고 PDF | 신청하기`

이미 신청:
`공식 공고 | 결과조회`

별도 신청폼이 있으면 `실제 신청폼` 추가.

### B. 접수·일정

- 접수 시작
- 접수 마감
- 정확한 마감시각
- 현재 상태
- 가능하면 남은 시간
- 서류대상 발표
- 서류제출
- 당첨발표
- 계약
- 입주

### C. 모집

- 기관
- 모집유형
- 신규/추가/예비/잔여/자격완화/상시
- 일반/특별
- 모집계층
- 타입
- 전용면적
- 실제 모집호수
- 예비인원
- 공가/예비 여부

### D. 위치

- 지역/권역
- 단지명
- 정확한 주소
- 가까운 역
- 노선
- 도보시간
- 강남 이동시간
- 판교 이동시간

### E. 이번 회차 임대조건

반드시 이번 모집회차 공식 자료 우선.

가능하면:

- 최소보증금 / 최대월세
- 기본보증금 / 기본월세
- 최대보증금 / 최소월세
- 보증금 전환 조건

이전 회차/블로그/유튜브 최저가를 사용하지 않는다.

### F. 자격

- 나이
- 미혼 여부
- 무주택
- 세대주/세대원
- 소득
- 자산
- 자동차
- 지역/거주/근무 요건
- 청약통장/납입횟수
- 부모 소득·자산 포함 여부
- 심사단위
- 공고의 공식 선정순위
- 1인가구 전용면적 제한
- 기타 당락조건

가능하면 `✅ 가능 / ⚠️ 추가확인 / ❌ 불가`로 판정하고 이유를 붙인다.

### G. 대출·실부담

보증금이 높다는 이유만으로 제외하지 않는다.

검토 가능한 제도:

- 청년전용 버팀목
- 청년전용 보증부월세대출
- 일반 버팀목
- 서울시 청년 임차보증금 지원
- HUG/HF 보증
- 단지/은행 협약대출

가능하면 계산:

- 제도상 최대 대출
- 실제 대상 여부
- 현실 예상 대출액
- 필요한 자기자금
- 예상 월이자
- 월세
- 관리비
- 최종 예상 월 주거비

### H. 중복신청

같은 공고 내부뿐 아니라 서로 다른 공고 A/B 동시신청 가능 여부까지 확인한다.

- 1세대 1주택
- 동일 모집 택1
- 다른 모집과 중복 가능/불가
- 중복 시 무효 여부

필요하면 `⚠️ 택1` 표시.

## 8. 국민임대는 단지 단위로 분해

국민임대 대형공고를 공고명 한 줄로 끝내지 않는다.

실제 단지별로 펼친다.

예: 세곡 / 강일 / 고덕 / 마곡 / 우면 / 내곡 / 장지 / 위례 / 신정 등.

단지별 필수 확인:

- 공가 모집인지 예비 모집인지
- 공가 0인지 실제 공가 존재인지
- 타입
- 전용면적
- 모집호수
- 예비인원
- 보증금/월세
- 주소/교통
- 사용자 자격

공가 0을 즉시 입주 가능한 공가처럼 표현 금지.

## 9. 후보 정렬 방식

숫자 추천순위를 매기지 않는다.

같은 그룹 내 표시 순서는 다음 요소를 종합해서 자연스럽게 배열한다.

- 마감 임박도
- 실제 신청 가능성
- 자격 적합성
- 강남/판교 접근성
- 비용/자기자금
- 모집규모/당첨 가능성
- 주거수준/장기거주
- 신청/서류 난이도

표시는 이모티콘으로만 구분한다.

## 10. 패스 / 탈락 / 보류

패스:
- 상세 반복 금지
- 지도 제외
- 행동 우선목록 제외
- 필요 시 한 줄만

탈락:
- 사용자 직접 확인 시 현재 보고와 지도에서 제거
- 결과확인 대상으로 반복 금지
- 원장 이력만 유지

보류:
- 영구 제외 아님
- 새 가격/자격/일정/공급호수 나오면 재검토 가능

## 11. 이미 신청한 공고

신규후보와 분리해 별도 그룹/지도에서 추적한다.

`신청 → 결과 → 당첨/예비 → 서류 → 계약 → 입주`

개인 결과는 공개검색으로 추정하지 않고 사용자 직접 확인을 최우선한다.

## 12. 최종 출력 검수 체크

보고 전 반드시 확인:

- [ ] KST 현재시각 반영
- [ ] 오늘·내일 지도 있음
- [ ] 2~3일 내 지도 있음
- [ ] 4~7일 내 지도 있음
- [ ] 그 이후 예정 지도 있음
- [ ] 이미 신청한 공고 지도 있음
- [ ] 서로 다른 일정 그룹이 한 지도에 섞이지 않음
- [ ] 패스/탈락 공고 지도에서 제거
- [ ] 정확주소 없는 곳에 추정 핀 없음
- [ ] 사용자 추천 숫자순위 없음
- [ ] 별점 없음
- [ ] 공고의 공식 선정순위는 필요 시 정확히 표시
- [ ] 국민임대는 단지별 공가/예비 구분
- [ ] 공식 링크가 공고 바로 아래 있음
- [ ] 대출/자기자금/월주거비 가능한 범위까지 계산
