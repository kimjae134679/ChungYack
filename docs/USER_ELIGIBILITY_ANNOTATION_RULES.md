# 사용자 조건 판정 표시 규칙

최종 갱신: 2026-08-31 KST

이 문서는 청약/임대주택 공고를 사용자 현재 조건에 맞춰 표시하는 판정 규칙이다.

## 1. 기본 원칙

공고를 찾는 단계에서는 사용자 조건에 맞지 않는다는 이유만으로 탐색 자체에서 삭제하지 않는다.

현재 공고 보고/HTML에는 가능한 한 발견된 공고를 유지하고, 각 공고의 `내 조건 판정` 또는 기존 `참고/비고/나에게 부합하지 않는 이유` 영역에서 사용자에게 실제 신청 가능성이 있는지를 명확히 표시한다.

단, 사용자가 직접 `패스/제외`한 공고와 이미 `탈락 종료`한 공고는 기존 프로젝트 규칙대로 활성 상세/지도에서 제외할 수 있다.

## 2. 판정 표식

- `✅ 신청 적합` — 현재 확인된 사용자 조건과 공고의 필수 자격 사이에 명확한 충돌이 없고 실제 신청 대상으로 볼 수 있음.
- `🟢 가능` — 현재 확인된 범위에서 신청 가능. 다만 공식 서류심사 전 확정 자격이라고 단정하지 않음.
- `⚠️ 비벼볼 만함` — 핵심 조건 대부분은 맞지만 소득 산정, 부모 포함 여부, 근무업종, 지역우선, 자산, 세대판정 등 1개 이상의 변수 확인이 필요함. 바로 버리지 않고 우선 확인할 후보.
- `🟠 조건부` — 특정 거주기간, 근무지역, 추천대상, 직종/산업코드, 청약통장 납입횟수 등 추가조건 충족 여부에 따라 가능/불가가 갈림.
- `❌ 절대 불가` / `❌ 사실상 신청 불가` — 공식 공고의 하드 자격요건과 사용자 현재 조건이 명확히 충돌하여 이번 회차 신청자격이 없음. 예: 신혼부부 전용인데 혼인/예비혼인 조건 필수, 특정 직업군 전용인데 해당 직업군이 아님, 필수 거주기간을 충족하지 못함 등.
- `⏸ 사용자 보류` — 자격과 무관하게 사용자가 일단 보류한 공고.

## 3. `❌ 절대 불가` 사용 기준

추정이나 경쟁률 때문에 `절대 불가`라고 쓰지 않는다.

아래처럼 공고의 명시적 하드 조건과 사용자 현재 조건이 직접 충돌할 때만 사용한다.

- 혼인/예비혼인 필수
- 특정 직업/예술분야/사회적경제조직 종사자 필수
- 필수 거주기간/지역요건 명백한 미충족
- 연령 제한 명백한 초과/미달
- 자산/소득 상한을 공식 산식으로 계산해 명백히 초과
- 주택소유 등 필수 자격의 명백한 위반

소득 산식, 부모 포함, 세대판정, 근무업종 코드, 자산평가 등 해석·증빙이 필요한 경우에는 `❌ 절대 불가`로 단정하지 않고 `⚠️ 비벼볼 만함` 또는 `🟠 조건부`로 둔다.

## 4. 공고 카드/HTML 표시 — 기존 참고영역을 강화

새 배지·새 카드·별도 위젯을 계속 추가하지 않는다.

공고 카드에 이미 존재하는 `참고/비고/기본 추천조건 불일치/나에게 부합하지 않는 이유` 영역을 그대로 사용하고, 그 영역의 색상과 첫 문장을 판정에 따라 강화한다.

각 공고에는 가능한 한 아래 3가지를 같은 영역에 표시한다.

`결론 | 판정 근거 | 추가 확인할 것`

### 시각 강조

- `❌ 절대 불가 / 사실상 신청 불가` → **연한 빨강 배경 + 빨간 테두리/왼쪽 강조선 + 진한 빨간 제목**
- `🟠 조건부 / ⚠️ 비벼볼 만함` → **연한 주황·노랑 배경 + 주황 강조선**
- `🟢 가능 / ✅ 신청 적합` → **연한 녹색 배경 + 녹색 강조선**
- 아직 판단자료 부족 → 중립 회색/파랑 계열 유지

카드 상단에 같은 내용을 중복해서 새로 만들지 않는다. 사용자가 카드를 아래로 읽을 때 기존 참고영역 하나만 봐도 결론이 확실히 보여야 한다.

예시:

- `🟢 가능 | 청년·무주택 조건 충돌 없음 | 소득 산정 기준 최종 확인`
- `⚠️ 비벼볼 만함 | 기본 청년자격 가능 | 부모소득 포함 여부 확인 필요`
- `🟠 조건부 | 지역전략산업 종사자 경로 존재 | 회사 업종코드가 대상산업인지 확인`
- `❌ 사실상 신청 불가 | 사회적경제조직 종사자만 신청 가능 | 현재 알려진 조건과 필수 직군 요건이 명확히 불일치`

## 5. 설명 문장 규칙

판정 제목만 쓰고 끝내지 않는다.

반드시 바로 아래 설명에서 다음 중 어느 상태인지 자연어로 명확히 적는다.

- `현재 조건상 신청 가능성이 높음`
- `한두 조건만 확인되면 비벼볼 만함`
- `특정 추가조건을 충족해야만 가능`
- `현재 알려진 조건으로는 사실상 신청 불가능`

특히 전용 직업/혼인/거주기간 같은 하드요건 공고는 `왜 안 되는지`를 한 문장으로 바로 적는다.

## 6. 보고 방식

- `오늘꺼 알려줘`에서 자격이 안 맞는 공고를 발견했다고 해서 탐색 누락으로 만들지 않는다.
- 사용자와 무관한 전용공고도 `숨은공고/참고` 영역에 간단히 남기고 `❌ 절대 불가` 근거를 적을 수 있다.
- 실제 행동 후보는 `✅/🟢/⚠️/🟠` 위주로 자세히 보여준다.
- `❌ 절대 불가`는 상세 설명을 과도하게 늘리지 않고 불가 이유를 1~2줄로 명확히 표시한다.
- 경쟁률이 높거나 입지가 멀다는 이유는 자격 불가가 아니다. 그런 경우는 자격판정과 별도로 입지/경쟁/비용 참고사항에 표시한다.

## 7. 개인정보/상태 사용 원칙

판정에는 프로젝트에 사용자가 직접 제공하고 원장에 정리된 최신 조건만 사용한다. 사용자가 새 소득, 거주, 직장, 혼인, 차량, 자산, 세대 상태 등을 알려주면 이후 판정부터 최신 상태로 재평가한다.

공식 공고의 세부 산식이나 제출기관 최종심사보다 사용자 조건 판정을 우선한다고 표현하지 않는다. 보고의 판정은 신청 의사결정 지원용이며 최종 자격은 공식 심사 결과가 기준이다.
