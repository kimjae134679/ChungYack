## 7. 후보 검증 체크

후보를 찾았다고 끝이 아니다.

- [ ] 공식 공고 페이지 확보
- [ ] 모집공고 PDF 확보
- [ ] 이번 회차 공급호수표 확인
- [ ] 이번 회차 임대조건표 확인
- [ ] 정확 주소 확인
- [ ] 실제 신청 페이지 확인
- [ ] 접수 시작/마감시각 확인
- [ ] 청년 자격 실제 적용 확인
- [ ] 중복신청/택1 제한 확인
- [ ] 결과/서류/계약 일정 확인

탐색 완료는 `찾았다`가 아니라 **전수 확인 + 공식 검증이 끝난 상태**를 의미한다.
