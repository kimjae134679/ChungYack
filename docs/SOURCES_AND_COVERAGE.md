## 5. 민간 집계 / 발견용

- [ ] 집지켜
- [ ] 내집다오
- [ ] LH임대알리미
- [ ] 주거나침반
- [ ] 사용자가 확인한 `임대주택` 앱 등 공개 집계 앱
- [ ] 기타 공개 집계 서비스

**민간 앱보다 공고를 덜 찾으면 탐색 미완료로 본다.**

사용자가 `앱에는 있는데 보고엔 없다`고 알려주면:

1. 해당 후보 식별
2. 왜 누락됐는지 확인
3. 공식 공고 검색
4. PDF/공급표/임대조건표 검증
5. 실제 신청 가능 여부 판정

## 7. 국민임대 별도 검증

대형 국민임대 공고는 공고 한 줄로 끝내지 않는다.

- [ ] 실제 공급단지별 분해
- [ ] 공가/예비 구분
- [ ] 공가 0 여부
- [ ] 타입별 전용면적
- [ ] 실제 공급호수
- [ ] 예비인원
- [ ] 이번 회차 보증금/월세
- [ ] 정확주소
- [ ] 역/교통
- [ ] 사용자 자격

예: 세곡 / 강일 / 고덕 / 마곡 / 우면 / 내곡 / 장지 / 위례 / 신정 등.

## 8. 후보 공식 검증 체크

후보를 찾았다고 끝이 아니다.

- [ ] 공식 공고 페이지 확보
- [ ] 모집공고 PDF 확보
- [ ] 이번 회차 공급호수표 확인
- [ ] 이번 회차 임대조건표 확인
- [ ] 정확 주소 확인
- [ ] 실제 신청 페이지 확인
- [ ] KST 접수 시작/마감시각 확인
- [ ] 청년 자격 실제 적용 확인
- [ ] 부모 소득·자산 포함 여부 확인
- [ ] 중복신청/택1 제한 확인
- [ ] 서로 다른 공고 간 중복 가능 여부 확인
- [ ] 결과/서류/계약 일정 확인
- [ ] 대출 대상 가능성 검토
- [ ] 자기자금/월이자/월세/관리비/총 월주거비 계산 가능한지 검토

탐색 완료는 `찾았다`가 아니라 **전수 확인 + 민간 누락 역검증 + 공식 검증이 끝난 상태**를 의미한다.
