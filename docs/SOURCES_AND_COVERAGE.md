## 5. 민간 집계 / 정리 / 발견용

다음 사이트는 후보 발견뿐 아니라 **대형공고를 사람이 보기 쉽게 재구성한 표·요약·지도 구조를 분석하는 참고원**으로 적극 활용한다.

- [ ] 집지켜
- [ ] 내집다오
- [ ] LH임대알리미
- [ ] 주거나침반 — https://jugeo.co.kr/
  - 공고 원문 페이지 연결, 주택형/공급구분/모집호수/임대조건/일정의 구조화 확인
  - 대형 SH/LH 공고에서 단지 묶음이 실제 어떤 하위 단지로 구성되는지 역검증
- [ ] 돈브리핑 — https://donbrief.com/
  - 대형 국민임대·공공임대의 공가/예비, 구별·면적별 물량, 자격을 빠르게 비교하는 참고원
- [ ] DearMyHealths 청약 정리 — https://dearmyhealths.com/
  - 2026 SH 국민임대처럼 대형 공급공고를 자치구/지구/형/모집세대수/보증금/월세 표로 한 화면에 정리한 페이지를 적극 참고
  - 단, 여러 실제 단지를 `세곡지구`, `강일리버파크`, `마곡엠밸리`처럼 하나의 지구 행으로 합친 경우 반드시 다시 개별 단지로 분해
- [ ] 곰두리/주거복지 공고 미러·게시판 — https://www.gomduri.com/
  - 공식 공고를 놓쳤을 때 후보 발견·공고명/일정 확인용
- [ ] 사용자가 확인한 `임대주택` 앱 등 공개 집계 앱
- [ ] 기타 공개 집계 서비스

**중요:** 민간 정리 사이트가 공식자료보다 보기 편하면 그 구조를 활용하되, 숫자·주소·자격·공가/예비·임대료를 그대로 확정하지 않는다.

`민간 정리표 확인 → 공식 공고/PDF 대조 → 지구 묶음이면 실제 단지별 분해 → 정확주소/공급호수/공가/예비/임대료 확정`

**민간 앱보다 공고를 덜 찾으면 탐색 미완료로 본다.**

사용자가 `앱에는 있는데 보고엔 없다`고 알려주면:

1. 해당 후보 식별
2. 왜 누락됐는지 확인
3. 공식 공고 검색
4. PDF/공급표/임대조건표 검증
5. 실제 신청 가능 여부 판정

## 7. 국민임대 / SH 대형공고 별도 검증

대형 국민임대·SH 다단지 공고는 공고 한 줄로 끝내지 않는다.

- [ ] 실제 공급단지별 분해
- [ ] `지구명/대표단지`로 묶인 행은 하위 실제 단지까지 전개
- [ ] 공가/예비 구분
- [ ] 공가 0 여부
- [ ] 타입별 전용면적
- [ ] 실제 공급호수
- [ ] 예비인원
- [ ] 신청자수/공식 경쟁률(발표 후)
- [ ] 이번 회차 보증금/월세
- [ ] 각 실제 단지의 정확한 도로명주소
- [ ] 역/교통
- [ ] 사용자 자격

특히 `강일리버파크1~10`, `고덕리엔파크1~3`, `강동리버스트4·6·7·8`, `세곡지구 강남신동아 외`, `마곡지구 마곡엠밸리`처럼 **청약 선택 단위는 지구인데 실제 주거지는 여러 단지인 경우**:

1. 보고 표에는 청약 선택 단위를 유지한다.
2. 그 아래 `실제 배정 가능 단지/주소`를 전부 펼친다.
3. 지도는 실제 단지 주소 기준으로 핀을 잡는다.
4. 지구 대표주소 한 개만 찍어 전체 지구 위치인 것처럼 표현하지 않는다.
5. 어떤 하위 단지에 배정되는지 신청 시 확정되지 않으면 `당첨 후/무작위 배정 가능`을 명시한다.

예: 세곡 / 강일 / 고덕 / 마곡 / 우면 / 내곡 / 장지 / 위례 / 신정 등.

## 8. 후보 공식 검증 체크

후보를 찾았다고 끝이 아니다.

- [ ] 공식 공고 페이지 확보
- [ ] 모집공고 PDF 확보
- [ ] 이번 회차 공급호수표 확인
- [ ] 이번 회차 임대조건표 확인
- [ ] 정확 주소 확인
- [ ] 실제 신청 페이지 확인
- [ ] KST 접수 시작/마감시각 확인
- [ ] 청년 자격 실제 적용 확인
- [ ] 부모 소득·자산 포함 여부 확인
- [ ] 중복신청/택1 제한 확인
- [ ] 서로 다른 공고 간 중복 가능 여부 확인
- [ ] 결과/서류/계약 일정 확인
- [ ] 대출 대상 가능성 검토
- [ ] 자기자금/월이자/월세/관리비/총 월주거비 계산 가능한지 검토

탐색 완료는 `찾았다`가 아니라 **전수 확인 + 민간 누락 역검증 + 공식 검증이 끝난 상태**를 의미한다.
