# Eligibility Profile — 공고 판정용

최종 갱신: 2026-08-30 KST

> 이 문서는 청약 공고의 1차 자격 판정을 위한 운영 프로필이다. 공고별 기준일/산정방식이 다르므로 **최종 판정은 반드시 해당 모집공고 PDF 기준**으로 한다.

## 현재 파악된 기본 조건

- 혼인: 미혼
- 자녀: 없음
- 주택: 무주택 세대주로 파악
- 차량: 없음
- 출생연도: 2001년생 언급
- 재직 시작: 2026-02-02
- 연봉: 약 3,600만원으로 보고됨
- 월 세전 급여: 약 300만원으로 보고됨
- 식대: 월 24만원 언급
- 복지포인트: 연 300만원 언급

## 중요 판정 원칙

위 수치를 공고에 기계적으로 대입하지 않는다.

반드시 확인:

- 공고 기준일의 나이
- 청년 정의
- 무주택 심사단위
- 세대주/세대원 요건
- 본인만 소득심사인지 세대/부모 포함인지
- 전년도 도시근로자 월평균소득 기준인지
- 현재소득/건강보험료/원천징수/소득금액증명 기준인지
- 자산 및 자동차 기준
- 거주지/근무지 순위
- 청약통장/납입횟수 필요 여부
- 1인가구 전용면적 제한

## 판단 시 금지

- 연봉만 보고 월평균소득 자격을 바로 확정하지 않는다.
- 이전 공고의 소득 판정 방식을 새 공고에 그대로 적용하지 않는다.
- 부모 소득/자산 포함 여부를 공고 확인 없이 단정하지 않는다.
- 재직기간/소득 발생기간이 짧은 경우 임의 연환산으로 확정하지 않는다.

## 갱신 규칙

사용자가 소득, 재직, 주거상태, 차량, 혼인상태 등 **청약 자격에 직접 영향을 주는 정보가 바뀌었다고 명시하면** 이 문서를 갱신한다.
