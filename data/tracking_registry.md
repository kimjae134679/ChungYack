## 상태 변경 기록 규칙

사용자가 다음 표현을 쓰면 즉시 반영한다.

- `관심` → 관심·검토
- `넣는 중 / 넣자` → 신청 진행중 또는 신청예정 상태로 추적
- `신청했어 / 넣었어` → 신청완료
- `결과 봐야 함` → 결과확인 필요
- `예비 ○번` → 예비
- `서류 냈어 / 서류 대상` → 서류
- `계약했어` → 계약·입주
- `보류` → 보류
- `패스 / 넘기자 / 제외` → 패스
- `탈락` → 종료/탈락으로 이동하고 현재 보고·지도에서 제거

공식 발표시각이 경과했지만 사용자의 개인 결과가 확인되지 않은 신청건은 `결과확인 필요` 또는 `서류대상 확인 긴급`으로 승격하되, 당첨/예비/탈락 여부는 임의 추정하지 않는다.
사용자가 직접 알려준 개인 상태를 공개 웹검색보다 우선한다.
일반 보고에서는 추천 숫자순위/별점을 기본적으로 사용하지 않는다. 단 사용자가 직접 우선순위 정렬을 요청한 비교표/앱에서는 숫자 정렬을 사용할 수 있다.
신청완료로 바뀐 공고는 신규후보 표에서 제거하고 `reports/current_dashboard.html`의 이미 신청 섹션으로 이동되도록 `data/current_dashboard_state.js`도 같은 회차에 갱신한다.
