## 상태 변경 기록 규칙

사용자가 다음 표현을 쓰면 즉시 반영한다.

- `관심` → 관심·검토
- `넣는 중` → 신청 진행중
- `신청했어 / 넣었어` → 신청완료
- `결과 봐야 함` → 결과확인 필요
- `예비 ○번` → 예비
- `서류 냈어 / 서류 대상` → 서류
- `계약했어` → 계약·입주
- `보류` → 보류
- `패스 / 넘기자 / 제외` → 패스

공식 발표시각이 경과했지만 사용자의 개인 결과가 확인되지 않은 신청건은 `결과확인 필요`로 승격하되, 당첨/예비/탈락 여부는 임의 추정하지 않는다.
사용자가 직접 알려준 개인 상태를 공개 웹검색보다 우선한다.
추천 숫자순위/별점은 출력하지 않고 이모티콘으로 상태와 긴급도만 표시한다. 단, 공고 자체의 공식 선정순위는 그대로 기록한다.
