## 6. APK 상태

### 소스

`v0.4.0`까지 GitHub main 반영 완료.

### 바이너리

아직 새 APK는 생성되지 않음.

최신 확인:

- run 33422986539
- job 99589659925
- conclusion: failure
- steps: `[]`
- runner_id: `0`
- runner_name: 빈 값

즉 checkout/Node/QA/Capacitor/Gradle 단계가 하나도 실행되지 않았다.

APK가 실패한 원인을 앱 코드 오류라고 기록하지 않는다. 현재는 GitHub Actions runner가 job step을 시작하기 전의 차단/할당 문제다.

상세: `ops/ANDROID_BUILD_BLOCKER.md`
